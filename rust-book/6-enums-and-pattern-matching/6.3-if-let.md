### Concise Control Flow

This chapter introduces `if let` and `let else` as concise alternatives to the `match` expression when you only care about one specific pattern and want to ignore everything else.

#### 1. The `if let` Syntax

The `if let` syntax allows you to combine `if` and `let` to handle values that match one pattern while ignoring the rest. It is essentially syntax sugar for a `match` expression that runs code only on a match and does nothing otherwise.

**The `match` Approach (Verbose):**
If you only want to handle `Some`, you still have to include `_ => ()` to satisfy exhaustiveness.

```rust
let config_max = Some(3u8);
match config_max {
    Some(max) => println!("The maximum is configured to be {max}"),
    _ => (),
}

```

**The `if let` Approach (Concise):**
This behaves exactly the same as the code above but with less boilerplate.

```rust
let config_max = Some(3u8);
if let Some(max) = config_max {
    println!("The maximum is configured to be {max}");
}

```

**Trade-off:** You gain conciseness (less typing/indentation) but lose the **exhaustive checking** that `match` enforces.

#### 2. `if let` with `else`

You can include an `else` block with `if let`. This block runs if the pattern does *not* match, equivalent to the `_` (catch-all) arm in a `match` expression.

```rust
let coin = Coin::Penny;
let mut count = 0;
if let Coin::Quarter(state) = coin {
    println!("State quarter from {state:?}!");
} else {
    count += 1;
}

```

#### 3. Staying on the "Happy Path" with `let else`

The `let else` syntax allows you to extract a value if a pattern matches, or **diverge** (return, break, or panic) if it doesn't. This keeps the "happy path" unindented and clear.

**The Problem (Nested `if let`):**
Trying to extract a value and return early using standard `if let` can be messy or require weird nesting.

```rust
fn describe_state_quarter(coin: Coin) -> Option<String> {
    // This assigns 'state' if matched, otherwise returns None immediately
    let state = if let Coin::Quarter(state) = coin {
        state
    } else {
        return None;
    };

    // "Happy path" continues here...
    if state.existed_in(1900) {
        Some(format!("{state:?} is pretty old, for America!"))
    } else {
        Some(format!("{state:?} is relatively new."))
    }
}

```

**The Solution (`let else`):**
This syntax binds the variable in the *outer* scope if it matches. If it fails, it executes the `else` block, which *must* diverge (exit the current flow).

```rust
fn describe_state_quarter(coin: Coin) -> Option<String> {
    // Clean extraction or early return
    let Coin::Quarter(state) = coin else {
        return None;
    };

    // 'state' is now available in this scope directly
    if state.existed_in(1900) {
        Some(format!("{state:?} is pretty old, for America!"))
    } else {
        Some(format!("{state:?} is relatively new."))
    }
}

```
