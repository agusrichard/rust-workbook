# 14.4 - Installing Binaries from Crates.io with `cargo install`

## High-Level Overview

`cargo install` lets you install binary crates from crates.io directly onto your local machine. It is a convenient way for Rust developers to use command-line tools written in Rust and shared on crates.io. Only crates with a **binary target** can be installed this way.

---

## What Is a Binary Target?

A **binary target** is a runnable program produced when a crate has:
- A `src/main.rs` file, **or**
- Another file explicitly declared as a binary in `Cargo.toml`

This is distinct from a **library target**, which produces a `.rlib` and is not independently runnable.

---

## Installation Location

Installed binaries are placed in the `bin/` folder of Cargo's installation root:

- Default path (when installed via [rustup.rs](https://rustup.rs)): `$HOME/.cargo/bin`

This directory must be in your `$PATH` for the installed binaries to be executable directly from the terminal.

---

## Example: Installing `ripgrep`

[`ripgrep`](https://crates.io/crates/ripgrep) is a fast, Rust-based alternative to `grep`.

```
$ cargo install ripgrep
```

**Output:**

```
    Updating crates.io index
  Downloaded ripgrep v14.1.1
  Downloaded 1 crate (213.6 KB) in 0.72s
  Installing ripgrep v14.1.1
   Compiling ...
    Finished `release` profile [optimized] target(s) in 6.73s
  Installing ~/.cargo/bin/rg
   Installed package `ripgrep v14.1.1` (executable `rg`)
```

After installation, the binary is available as `rg`:

```
$ rg --help
```

---

## Key Points

| Topic               | Detail                                                                 |
|---------------------|------------------------------------------------------------------------|
| Command             | `cargo install <crate-name>`                                           |
| What can be installed | Only crates with a binary target (`src/main.rs` or declared binary) |
| Install location    | `$HOME/.cargo/bin` (default with rustup)                               |
| `$PATH` requirement | `~/.cargo/bin` must be in `$PATH` to run installed tools               |
| Build profile       | Always uses the `release` profile — optimized for runtime performance  |
| Source              | Packages are downloaded from crates.io                                 |
