# Data Types

Rust is a **statically typed** language, meaning the compiler must know the data type of all variables at compile time. While Rust often infers types, explicit annotations are sometimes required (e.g., when converting strings to numbers).

Rust has two primary subsets of data types: **Scalar** and **Compound**.

## 1. Scalar Types

A scalar type represents a single value. Rust has four primary scalar types.

### A. Integer Types

Integers are numbers without fractional components.

- **Signed (`i`)**: Can be positive or negative. Range: to .
- **Unsigned (`u`)**: Always positive. Range: to .

| Length  | Signed  | Unsigned        |
| ------- | ------- | --------------- |
| 8-bit   | `i8`    | `u8`            |
| 16-bit  | `i16`   | `u16`           |
| 32-bit  | `i32`   | `u32` (Default) |
| 64-bit  | `i64`   | `u64`           |
| 128-bit | `i128`  | `u128`          |
| Arch    | `isize` | `usize`         |

- **Literals**: Decimal (`98_222`), Hex (`0xff`), Octal (`0o77`), Binary (`0b1111_0000`), Byte (`b'A'`).
- **Overflow**: In debug mode, overflow causes a panic. In release mode, it performs 2's complement wrapping (e.g., `256` becomes `0` in `u8`).

### B. Floating-Point Types

Numbers with decimal points, following the IEEE-754 standard.

- **`f64`**: The default type. 64-bit precision (double).
- **`f32`**: 32-bit precision (single).

### C. The Boolean Type

- **`bool`**: Has two values: `true` and `false`.
- Size: 1 byte.
- Used primarily in control flow (e.g., `if` statements).

### D. The Character Type

- **`char`**: Represents a Unicode Scalar Value.
- Size: 4 bytes.
- Written with single quotes (e.g., `'z'`, `'😻'`).
- Can represent accented letters, emojis, and more (ranging from U+0000 to U+10FFFF).

## 2. Compound Types

Compound types group multiple values into one type.

### A. The Tuple Type

- **Definition**: A fixed-length grouping of values with potentially different types.
- **Syntax**: `let tup: (i32, f64, u8) = (500, 6.4, 1);`
- **Access**:
- **Destructuring**: `let (x, y, z) = tup;`
- **Indexing**: `tup.0`, `tup.1`.

- **Unit**: The empty tuple `()` is called "unit" and represents an empty value or return type.

### B. The Array Type

- **Definition**: A fixed-length collection of values with the **same type**. Allocated on the stack.
- **Syntax**: `let a = [1, 2, 3, 4, 5];`
- **Type Annotation**: `[type; number_of_elements]` (e.g., `let a: [i32; 5] = ...`).
- **Initialization**: `let a = [3; 5];` (Create an array of 5 elements, all set to `3`).
- **Access**: Indexing `a[0]`.
- **Safety**: Accessing an invalid index causes a runtime panic (memory safety feature).
