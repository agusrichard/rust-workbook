# Comments

Comments are lines of text in source code used to leave notes for programmers. They are ignored by the compiler.

### Single-Line Comments

- **Syntax**: Start with two slashes `//`.
- **Behavior**: The comment continues until the end of the line.
- **Usage**: Can be placed on their own line or at the end of a line of code.

```rust
// This is a comment on its own line
let x = 5; // This is a comment at the end of a line

```

### Multi-Line Comments

- **Idiomatic Style**: Rust programmers typically use multiple single-line comments for long explanations.

```rust
// So we're doing something complicated here, long enough that we need
// multiple lines of comments to do it! Whew! Hopefully, this comment will
// explain what's going on.

```

- **Alternative Syntax**: You can also use `/*` to start and `*/` to end a block comment, though `//` is more common.

```rust
/* This is also a valid
   multi-line comment */

```

### Documentation Comments

Rust also supports **documentation comments** (which typically start with `///`), but these are covered in a later chapter (Chapter 14).
