# Control Flow

Control flow allows you to run code based on conditions or repeatedly. The primary constructs in Rust are `if` expressions and loops.

### `if` Expressions

An `if` expression branches code execution based on a condition.

- **Syntax:** `if condition { block } else { block }`
- **Boolean Requirement:** The condition **must** be a `bool`. Rust will not automatically convert numbers (like `0` or `1`) to booleans.
- **Else If:** You can handle multiple conditions with `else if`. Rust executes the block for the _first_ true condition and ignores the rest.

```rust
let number = 6;
if number % 4 == 0 {
    println!("divisible by 4");
} else if number % 3 == 0 {
    println!("divisible by 3");
} else {
    println!("not divisible by 4 or 3");
}

```

**Using `if` in a `let` Statement**
Because `if` is an expression, it can be used on the right side of a `let` statement to assign a value.

- **Type Consistency:** The return values of all `if` and `else` arms must be the **same type**.

```rust
let condition = true;
let number = if condition { 5 } else { 6 }; // number is 5

```

### Repetition with Loops

Rust provides three types of loops: `loop`, `while`, and `for`.

#### 1. `loop`

Repeats a block of code forever until explicitly told to stop using `break`.

- **Returning Values:** You can pass a value to `break` to return it from the loop expression.

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};

```

- **Loop Labels:** Use labels (starting with `'`) to disambiguate nested loops. `break` and `continue` apply to the innermost loop unless a label is specified.

```rust
'outer: loop {
    loop {
        if condition {
            break 'outer; // Breaks the outer loop
        }
    }
}

```

#### 2. `while`

A conditional loop that runs _while_ a condition is true.

```rust
while number != 0 {
    println!("{number}!");
    number -= 1;
}

```

#### 3. `for`

Used to loop through a collection or a range. This is the most safe and concise loop type in Rust, avoiding index out-of-bounds errors.

- **Looping over a collection:**

```rust
let a = [10, 20, 30, 40, 50];
for element in a {
    println!("the value is: {element}");
}

```

- **Looping over a range:**

```rust
// 1..4 is a Range (1, 2, 3). .rev() reverses it.
for number in (1..4).rev() {
    println!("{number}!");
}

```
