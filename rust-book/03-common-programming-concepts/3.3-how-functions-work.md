# Functions

Functions are a core building block in Rust. The entry point of most programs is the `main` function. Rust functions use **snake_case** for naming (lowercase letters with underscores).

### Defining Functions

- **Syntax:** Use the `fn` keyword followed by the function name, parentheses `()`, and curly brackets `{}` for the body.
- **Location:** Functions can be defined anywhere in the source code (before or after the caller), as long as they are in a visible scope.

```rust
fn main() {
    println!("Hello, world!");
    another_function();
}

fn another_function() {
    println!("Another function.");
}

```

### Parameters

Parameters are variables declared in a function's signature. When calling the function, you pass concrete values called _arguments_.

- **Type Annotations:** You **must** explicitly declare the type of each parameter. This design choice allows the compiler to give helpful error messages without needing type inference elsewhere.
- **Multiple Parameters:** Separate parameters with commas.

```rust
fn print_labeled_measurement(value: i32, unit_label: char) {
    println!("The measurement is: {value}{unit_label}");
}

```

### Statements and Expressions

Rust is an **expression-based** language, distinguishing clearly between statements and expressions.

- **Statements:** Instructions that perform an action and **do not return a value**.
- Example: `let y = 6;` is a statement.
- You cannot assign a statement to a variable (e.g., `let x = (let y = 6);` is invalid).

- **Expressions:** Evaluate to a resulting value.
- Example: `5 + 6`, calling a function, or a block `{}`.
- **No Semicolon:** Expressions do not end with a semicolon. Adding a semicolon turns an expression into a statement, causing it to return `()` (unit) instead of its value.

**Block Expression Example:**

```rust
let y = {
    let x = 3;
    x + 1 // No semicolon here; this expression returns 4
};

```

### Return Values

Functions can return values to the caller.

- **Syntax:** Declare the return type after an arrow `->`.
- **Implicit Return:** The return value is the value of the **final expression** in the function body.
- **Explicit Return:** You can use the `return` keyword for early returns, but it is less common for the final value.

```rust
fn five() -> i32 {
    5 // Implicit return (no semicolon)
}

fn plus_one(x: i32) -> i32 {
    x + 1 // Returns x + 1
}

```

**Common Error:** If you add a semicolon to the last line (`x + 1;`), it becomes a statement. The function will then return `()` (unit) instead of `i32`, causing a compilation error.
