# Method Syntax

Methods are similar to functions (declared with `fn`, having parameters and return values), but they are defined within the context of a struct, enum, or trait object. Their first parameter is always `self`, which represents the instance on which the method is called.

## Defining Methods

To define a method, use an `impl` (implementation) block for the struct. The first parameter in the method signature must be `self`.

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let rect1 = Rectangle {
        width: 30,
        height: 50,
    };

    println!(
        "The area of the rectangle is {} square pixels.",
        rect1.area()
    );
}

```

### The `self` Parameter

- `&self`: Short for `self: &Self`. This borrows the instance immutably (read-only). This is the most common case.
- `&mut self`: Short for `self: &mut Self`. This borrows the instance mutably, allowing the method to change the instance.
- `self`: Short for `self: Self`. This takes ownership of the instance, consuming it. This is rare and usually used when transforming `self` into something else.

### Method Calls as Syntactic Sugar

Rust automatically handles referencing and dereferencing when you call a method with dot notation. The call `r.area()` is syntactic sugar for `Rectangle::area(&r)`. Rust will automatically add `&`, `&mut`, or `*` to `r` so it matches the signature of the method.

## Methods with More Parameters

Methods can take additional parameters after `self`. These work just like normal function parameters.

```rust
impl Rectangle {
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}

fn main() {
    let rect1 = Rectangle { width: 30, height: 50 };
    let rect2 = Rectangle { width: 10, height: 40 };

    println!("Can rect1 hold rect2? {}", rect1.can_hold(&rect2));
}

```

## Associated Functions

All functions defined within an `impl` block are called _associated functions_. You can define functions that do _not_ have `self` as their first parameter. These are often used as constructors (like `String::from`).

To call an associated function, use the `::` syntax (e.g., `Rectangle::square(3)`).

```rust
impl Rectangle {
    fn square(size: u32) -> Self {
        Self {
            width: size,
            height: size,
        }
    }
}

fn main() {
    let sq = Rectangle::square(3);
}

```

## Multiple `impl` Blocks

A struct is allowed to have multiple `impl` blocks. This can be useful for organization, although typically valid, separate blocks are more commonly seen when implementing generic traits (discussed in later chapters).

```rust
impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

impl Rectangle {
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}

```
