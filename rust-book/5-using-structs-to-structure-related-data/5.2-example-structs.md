# An Example Program Using Structs

To demonstrate when to use structs, this chapter walks through a program that calculates the area of a rectangle. It starts with single variables and refactors the code until it uses structs.

## Attempt 1: Using Separate Variables

The initial attempt uses separate variables for width and height.

```rust
fn main() {
    let width1 = 30;
    let height1 = 50;

    println!(
        "The area of the rectangle is {} square pixels.",
        area(width1, height1)
    );
}

fn area(width: u32, height: u32) -> u32 {
    width * height
}

```

**Issue:** The `area` function takes two parameters (`width` and `height`), but it is not clear elsewhere in the program that these two values are related to the same object.

## Attempt 2: Refactoring with Tuples

The next step is to group the data using a tuple.

```rust
fn main() {
    let rect1 = (30, 50);

    println!(
        "The area of the rectangle is {} square pixels.",
        area(rect1)
    );
}

fn area(dimensions: (u32, u32)) -> u32 {
    dimensions.0 * dimensions.1
}

```

**Issue:** While the data is grouped, the code is less clear. We have to index into the tuple (`dimensions.0`, `dimensions.1`), making it unclear which value represents width and which represents height.

## Attempt 3: Refactoring with Structs

We can add meaning by labeling the data using a struct.

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

fn main() {
    let rect1 = Rectangle {
        width: 30,
        height: 50,
    };

    println!(
        "The area of the rectangle is {} square pixels.",
        area(&rect1)
    );
}

fn area(rectangle: &Rectangle) -> u32 {
    rectangle.width * rectangle.height
}

```

**Analysis:**

- We define a `Rectangle` struct with named fields `width` and `height`.
- The `area` function now takes one parameter: a reference to a `Rectangle` instance (`&Rectangle`). We use a reference so `main` retains ownership of `rect1`.
- Accessing fields uses clear dot notation (e.g., `rectangle.width`).

## Adding Functionality with Derived Traits

By default, structs do not implement the `Display` trait, meaning you cannot print them directly with `println!("{}", rect1)`.

### Using `#[derive(Debug)]`

To print a struct for debugging purposes, we can add the `#[derive(Debug)]` attribute and use the `{:?}` or `{:#?}` (pretty-print) formatter.

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

fn main() {
    let rect1 = Rectangle {
        width: 30,
        height: 50,
    };

    // {:?} prints on one line, {:#?} spreads it across multiple lines
    println!("rect1 is {rect1:?}");
}

```

### Using the `dbg!` Macro

The `dbg!` macro is another tool for debugging. It:

1. Takes ownership of an expression.
2. Prints the file, line number, and resulting value to `stderr`.
3. Returns the value (passing ownership back).

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

fn main() {
    let scale = 2;
    let rect1 = Rectangle {
        // Wraps the expression to print its result (60) and return it
        width: dbg!(30 * scale),
        height: 50,
    };

    // Prints the whole struct value to stderr
    dbg!(&rect1);
}

```
