# Hello, Cargo!

Cargo is Rust's official build system and package manager. It automates tasks like building code, downloading dependencies (called "crates"), and managing projects. Most Rust projects use Cargo.

### Installation Check

If you installed Rust via the official installer, Cargo is already installed. Verify it by running:

```bash
$ cargo --version

```

### Creating a Project

To create a new project named `hello_cargo`:

```bash
$ cargo new hello_cargo
$ cd hello_cargo

```

This generates a directory with the following structure:

- **`Cargo.toml`**: The configuration file for the project (in TOML format). It defines the package name, version, edition, and dependencies.
- **`src/main.rs`**: The source code file. Cargo expects source code to live in the `src` directory.
- **Git Integration**: Cargo automatically initializes a new Git repository and adds a `.gitignore` file (unless already inside an existing repo).

### Building and Running

Cargo provides several commands to manage the build process:

- **`cargo build`**: Compiles the project.
- Creates an executable in `target/debug/`.
- The first run creates `Cargo.lock` to track exact dependency versions.

- **`cargo run`**: Compiles (if necessary) and runs the executable in one step.
- This is the most common way to run projects during development.

- **`cargo check`**: Quickly checks the code for compilation errors without producing an executable.
- Faster than building; useful for continuous feedback while coding.

### Building for Release

For the final version of your program, use the release profile:

```bash
$ cargo build --release

```

- Compiles with optimizations, making the code run faster.
- Compilation takes longer than a debug build.
- The executable is placed in `target/release/`.

### Key Benefits

- **Standardization**: Cargo standardizes project structure (source code in `src`, config in `Cargo.toml`).
- **Dependency Management**: Easily handles downloading and linking libraries.
- **Cross-Platform consistency**: Commands work the same on Linux, macOS, and Windows.
- **Easy Collaboration**: To work on an existing Cargo project, you simply clone the repo and run `cargo build`.
