# Installation

The first step to using Rust is installing it via `rustup`, a command-line tool for managing Rust versions and associated tools.

### Installing `rustup`

**On Linux or macOS**
Open a terminal and run the following command to download and install the latest stable version:

```bash
$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

```

- **Linker Requirements:** You will likely need a C compiler for the linker.
- **macOS:** Run `$ xcode-select --install`
- **Linux:** Install GCC or Clang (e.g., `build-essential` on Ubuntu).

**On Windows**

1. Go to [rust-lang.org/tools/install](https://www.rust-lang.org/tools/install) and follow the instructions.
2. You may be prompted to install Visual Studio to acquire the necessary C++ build tools (linkers and native libraries).

### Troubleshooting

To verify the installation, check the version:

```bash
$ rustc --version

```

You should see output similar to `rustc x.y.z (abcabcabc yyyy-mm-dd)`. If not, ensure Rust is in your system's `%PATH%` variable.

### Updating and Uninstalling

- **Update:** `$ rustup update`
- **Uninstall:** `$ rustup self uninstall`

### Local Documentation

Rust includes offline documentation. You can open it in your browser with:

```bash
$ rustup doc

```

### Text Editors and IDEs

You can use any text editor, but many have specific Rust support. Check the [Rust website](https://www.rust-lang.org/tools) for a list of supported editors and IDEs.

### Working Offline with This Book

Some examples in the book use external packages. To cache these dependencies ahead of time for offline use, run:

```bash
$ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.8.5 trpl@0.2.0

```

After running this, you can use the `--offline` flag with Cargo commands throughout the book.
