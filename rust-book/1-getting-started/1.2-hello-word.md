# Hello, World!

This section guides you through writing, compiling, and running your first Rust program.

### Creating a Project Directory

Rust does not enforce a specific directory structure, but it is recommended to create a dedicated folder for your projects.

**Linux, macOS, and PowerShell:**

```bash
$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world

```

**Windows CMD:**

```cmd
> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world

```

### Writing the Program

Create a file named `main.rs`. Rust source files always use the `.rs` extension.

**File:** `main.rs`

```rust
fn main() {
    println!("Hello, world!");
}

```

### Compiling and Running

Rust is an **ahead-of-time compiled** language. This means you must compile the source code into a binary executable before running it.

1. **Compile:** Run the Rust compiler (`rustc`) on your source file.

```bash
$ rustc main.rs

```

2. **Run:** Execute the resulting binary.

- **Linux/macOS:** `$ ./main`
- **Windows:** `> .\main`

**Output:**

```text
Hello, world!

```

### Anatomy of a Rust Program

- **`fn main() { ... }`**: Defines the `main` function. This is the entry point for every executable Rust program.
- **`{}`**: Curly brackets enclose the function body.
- **`println!("Hello, world!");`**:
- **`println!`**: This is a **macro**, indicated by the `!`. A normal function call would be `println` (without the `!`).
- **`"Hello, world!"`**: The string argument passed to the macro.
- **`;`**: The semicolon marks the end of the expression.

### Key Takeaways

- **Separate Steps:** Unlike dynamic languages (Ruby, Python, JS), Rust separates compiling and running.
- **Portability:** Once compiled, the binary can be run on other systems without needing Rust installed.
- **`rustc` vs. Cargo:** While `rustc` is sufficient for simple files, larger projects typically use **Cargo**, Rust's build system and package manager (introduced in the next section).
