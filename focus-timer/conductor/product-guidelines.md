# Product Guidelines

## User Experience (UX)
- **Tone & Voice:** Friendly and encouraging. The application should use positive reinforcement (e.g., "Great job! Time for a break.") to motivate the user, while maintaining clarity.
- **Error Handling:** Graceful and informative. When invalid input occurs, display a clear, non-intrusive message explaining the error and how to correct it. Avoid disrupting the user's workflow.
- **Navigation:** Standard navigation. Users should be able to navigate using arrow keys and confirm actions with `Enter` or `Space`. This ensures broad accessibility and familiarity.

## Visual Design (TUI)
- **Philosophy:** Balanced Minimalist. The interface should be clean and simple to prevent distraction, but utilize high contrast and a thoughtful color palette to clearly distinguish different states (e.g., active, paused, break) without becoming visually overwhelming.
- **Color Usage:** Functional color. Use color strategically to indicate status and progress, ensuring it enhances readability and focus rather than creating visual noise.
